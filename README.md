# MarkPoint

> **AI-Powered Civic & Environmental Issue Reporting Engine**
> Multimodal Computer Vision • 25-Meter Spatial Deduplication • Dynamic SLA Routing • "No Fake Closures" Before/After AI Verification Studio

---

## Quick Start Guide

The application is running and accessible at:
🔗 **[http://localhost:5173](http://localhost:5173)**

To start the application at any time, run:
```bash
npm run dev
```

---

## Key Features

1. **Instant Reporting (Photo / Voice)**: Snap a quick photo or speak a voice note — no complex forms or category selections needed.
2. **Automated AI Recognition (Gemini AI)**: Automatically identifies the problem, routes to the right municipal department (PWD, Health & Sanitation, Drainage / Water Board, etc.), and assigns priority and SLA deadlines.
3. **Smart Anti-Spam (25m Duplicate Finder)**: If multiple commuters report the same pothole or trash pile within 25 meters, it bundles them into 1 master ticket with upvotes instead of creating duplicate tickets.
4. **Problem Map (Location Visualizer)**: Interactive city map displaying problem pins, category filters, and live neighborhood issues.
5. **No Fake Closures**: When field crews submit a repair photo, AI compares it against the original to ensure genuine remediation before closing.
